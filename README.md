# DANCE SYNERGY REVIVAL 出演表（2026.9.22）

Instagram [@dance_synergy_project](https://www.instagram.com/dance_synergy_project/) の公式投稿から起こした、出演ダンサー×ナンバーの一覧アプリです。

- `index.html` … アプリ本体（単一ファイル・外部ライブラリなし）
- `data.json` … 元データ（出演者・ナンバー・辞退者）

ダンサー名をタップすると選択でき、「自分用リスト」で出演ナンバー一覧を画像として保存できます。

出典: Instagram @dance_synergy_project（2026-09-17取得）
